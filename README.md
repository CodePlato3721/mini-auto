# mini-auto

`mini-auto` is a small TypeScript browser automation prototype for the Sauce Demo checkout workflow. It supports two modes:

- Discovery: an LLM observes a live browser surface and records successful actions into a reusable capability artifact.
- Replay: a saved capability artifact runs deterministically without model calls, with policy checks, redacted evidence, outcome classification, and human handoff.

## Setup

Requirements:

- Node.js 22 or newer.
- Network access to `https://www.saucedemo.com/` for live discovery or replay.
- A model API key only for live LLM discovery.

Install dependencies:

```powershell
npm install
npx playwright install chromium
npm run build
```

## Configuration And Secrets

Evidence is always written to `./evidence`.
Live LLM discovery always uses `gpt-5-mini`.

`inputs.local.json`

```json
{
  "firstName": "Ada",
  "lastName": "Lovelace",
  "postalCode": "90210"
}
```

The CLI also loads a local `.env` file from the repo root when present.

password hardcode to `secret_sauce` for `https://www.saucedemo.com/`

```text
MINI_AUTO_MODEL_API_KEY=<your model API key>
MINI_AUTO_PASSWORD=secret_sauce
```

Do not commit `.env`, local input files, raw ad hoc evidence, or API keys.

Optional demo evidence:

```cmd
npm run demo:evidence
```

## How To Discover

Discovery opens the target site, lets the LLM choose one browser action at a time, and writes a replayable artifact to `./evidence/discovered-capability.json`.

Required:

- `MINI_AUTO_MODEL_API_KEY`
- `MINI_AUTO_PASSWORD`
- `--goal`
- `--target-url`
- optional `--inputs-file` for non-secret form data

## Discover Example

```cmd
node dist\src\interfaces\cli.js discover --goal "Log in as standard_user to Sauce Demo, add Sauce Labs Backpack to the cart, complete checkout with fake customer data, and verify the order confirmation." --target-url "https://www.saucedemo.com/" --inputs-file inputs.local.json
```

## How To Replay

Replay runs a saved artifact deterministically. It does not call the LLM. It uses the artifact steps, policy, locator candidates, inputs, and success checkpoint to report success or failure as JSON.

Required:

- `--artifact`
- optional `--goal` so the CLI can infer known Sauce Demo username/product inputs
- optional `--inputs-file` for non-secret form data

Pass the username and product in `--goal`.

## Replay Example

```cmd
node dist\src\interfaces\cli.js replay-only --artifact artifacts\sauce-demo-checkout.json --goal "Log in as standard_user, add Sauce Labs Backpack to the cart, and complete checkout." --inputs-file inputs.local.json
```

To replay an artifact generated by discovery:

```cmd
node dist\src\interfaces\cli.js replay-only --artifact evidence\discovered-capability.json --goal "Log in as standard_user, add Sauce Labs Backpack to the cart, and complete checkout." --inputs-file inputs.local.json
```

## Human Handoff

Handoff is enabled by default for replay. Replay pauses on explicit `handoff` steps, risky actions, or stuck replay states. It launches a headed Chromium session, prints the issue and evidence path in the CLI, and waits for the operator.

Operator commands:

```text
resume
resume: <what changed>
fail <reason>
```

When the browser is fixed, type `resume` or `resume: <what changed>`. If the issue cannot be solved, type `fail <reason>`.
